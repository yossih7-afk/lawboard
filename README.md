# לוח בקרת תיקים

מערכת משרדית לניהול תיקי בית משפט, מועדים ומשימות. רצה על מחשב אחד במשרד, ושאר המחשבים נכנסים דרך הדפדפן.

- התקנה: `LawBoard-Setup.bat` (נשלח בנפרד).
- עדכון: במערכת, הגדרות ועזרה ← עדכוני תוכנה ← "עדכן עכשיו".
- נתוני המשרד (תיקים, מסמכים) נשמרים רק במחשב המשרד, בתיקייה `data`, ולא נמצאים במאגר הזה.
